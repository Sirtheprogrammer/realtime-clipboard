    Browser Extension Setup

    MANIFEST V3 • CHROME & FIREFOX

    Save, autofill, and synchronize encrypted passwords, API keys, and credentials directly in your browser.

    Download Extension (.zip) GitHub Releases
    Chrome, Brave & Edge Chromium
    1. Download & unzip clipboard-vault-extension.zip to a folder.
    2. Open chrome://extensions (or edge://extensions).
    3. Turn on Developer mode (toggle switch in the top-right corner).
    4. Click Load unpacked and select the unzipped directory.
    Mozilla Firefox Gecko
    1. Download & unzip clipboard-vault-extension.zip to a folder.
    2. Navigate to about:debugging#/runtime/this-firefox.
    3. Click Load Temporary Add-on....
    4. Select the manifest.json file inside the unzipped folder.
